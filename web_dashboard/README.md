# Dashboard de Indicadores
## Putumayo · Cesar · La Guajira — Colombia

Dashboard interactivo de indicadores sociales, económicos y ambientales para los tres departamentos del proyecto ICSI.

**🌐 [Ver Dashboard en vivo](https://TU-USUARIO.github.io/TU-REPOSITORIO)**

---

### 59 indicadores · 9 dimensiones · 220 municipios · Datos 1990–2025

**Dimensiones incluidas:** Demografía · Ambiente · Economía · Empleo/Economía · Educación · Gobernanza · Salud · Seguridad · Servicios

---

### ¿Cómo usar?
1. Selecciona una **dimensión** (pestaña superior)
2. Elige un **indicador** del menú desplegable
3. Aplica **filtros** de departamento, municipio y rango de años
4. Explora el **mapa coroplético**, los **gráficos** y la **tabla de datos**
5. **Exporta** los datos filtrados a CSV

---

### Fuentes de datos
Los datos provienen de fuentes oficiales colombianas: DANE, MinEducación, MinSalud, DNP, Contraloría General, IGAC, entre otras. Ver el [Diccionario de Indicadores](../Diccionario_Indicadores.xlsx) para detalles por indicador.
